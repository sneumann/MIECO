# MIECO - Metabolite Identification Evidence Code Ontology

[//]: # "This file is meant to be edited by the ontology maintainer."

Welcome to the MIECO documentation!

MIECO is a DL ontology based on ECO to serve Metabolomics repositories with a formal ontology of terms describing evidences for molecule identification assertions. It was built in a middle-out approach, starting with a LC-MS Assay use case and then successively expanded to integrate other metabolomics techniques like NMR, UV, IR Spectrometry and others.
